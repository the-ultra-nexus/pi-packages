# extensions

本目录存放 pi 的**扩展**（extensions）与自定义工具。每个扩展一个独立子目录，自包含全部资源，可单独分发、单独安装。

## 已收录

| 路径 | 说明 |
| ---- | ---- |
| `pi-iterm2/` | iTerm2 集成扩展：标签页标题显示会话第一次提问、回答完成弹 macOS 系统通知、等待用户选择时提醒 |

## 约定

- 每个扩展一个独立子目录，自包含全部资源。
- 每个扩展目录内必须有 `README.md`，说明功能、安装方式与配置方法。
- 扩展保留自己的 `package.json`，可单独 `pi install` 安装。
