# skills

本目录存放 pi 可复用的技能（skills）。每个技能一个独立子目录，自包含其全部资源（主文件 `SKILL.md`、配置、引用文档），可单独复制分发。

## 现有技能

| 技能              | 一句话说明                                     |
| ----------------- | ---------------------------------------------- |
| `grill-all/`      | 以一轮轮提问不断拷问、压力测试你的思考与计划   |
| `multi-research/` | 多模型对照调研：并行不同模型调研同一问题，oracle 交叉检验后合并分析 |

## 新增技能

1. 在 `skills/` 下新建子目录，命名用 kebab-case。
2. 子目录内放主文件 `SKILL.md`（frontmatter 含 `name` 与 `description`，供代理按需加载）。
3. 写一个 `README.md`，说明该技能解决什么问题、目录结构、如何使用。
4. 技能内部引用其他文件时用相对路径，保证整个子目录可以整体移动。
